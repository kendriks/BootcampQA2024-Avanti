# BootcampQA2024-Avanti
Este repositório reúne os principais documento produzidos durante o Bootcamp de QA(2024) pelo Avanti, onde minha equipe e eu trabalhamos juntos com foco em manter a qualidade de software por meio de práticas de teste.
## 📂 Conteúdo:
- **Plano de teste:** Definição do escopo do projeto, tipos e níveis de testes, recursos, responsabilidades, registro dos padrões utilizados, escopo da automação de testes e croonograma.
- **Especificação de teste:** Detalhamento dos casos de teste.
- **Relatório de teste:** Registro dos testes executados, resultados obtidos e status de aprovação.
- **Relatório de bug:** Descrição estruturada dos defeitos encontrados durante os testes.

## 🛠️ Ferramentas e Tecnologias:
- **Comunicação:** Discord, WhatsApp, Google Meet.
- **Edição:** Google Docs, Screenprint.
- **Programação:** Cypress, VsCode.

## 🎯 Objetivo
Demonstrar a aplicação dos conceitos de planejamento, escrita, execução e documentação de bugs do projeto site Luma, uma aplicação demo utilizada para teste.
